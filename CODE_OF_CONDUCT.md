# Code of conduct

Be respectful and patient. Harassment, discriminatory language, threats, and publishing another person's private information are not welcome.

This applies to issues, pull requests, and other spaces representing this project. Use GitHub's **Report content** function for abusive content; do not publish personal information while reporting it.

Adapted from the upstream project's code of conduct under Apache-2.0, in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

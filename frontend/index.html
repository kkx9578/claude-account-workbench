Chrome 与网络环境

在每个账号的“管理”中绑定独立 Chrome 个人资料。请确保网络可正常访问 Claude；如使用 easyAI，可继续使用原有配置。如果登录链接打开在其他浏览器里，手动复制到对应 Chrome 资料。

手动重新识别

登录后点击“重新识别账号”，立即读取当前授权并核对邮箱；主页也有“重新识别账号”。普通缓存等待不会阻止身份识别，服务器限流时仍需等待。识别新账号后，确认保存会另行提示同步聊天并重启 Claude。

额度检查

点击“刷新额度”可立即查询当前账号，不受普通自动检查间隔限制；真实限流和15秒内的重复点击仍受保护。重新识别账号只核对身份，不会推迟额度检查。

当前账号每 15 分钟、其他账号每 30 分钟检查一次。限流后至少暂停 30 分钟，连续限流逐步延长；服务器要求更久时按服务器时间等待。等待时间会保存，重启和点击检查都不会绕过。新识别账号先保存身份，额度稍后检查。

共享的范围

账号登录快照与 Chrome 资料分开管理，本地代码和 Code 会话继续共用。普通云端聊天和运行中的任务不在接续范围内；这不是独立电脑或网络环境。
